# 三国放置 · 群雄逐鹿

一个纯前端的三国题材放置卡牌游戏，单页 HTML + 静态素材，无需构建、无需后端。

- 存档保存在浏览器本地（localStorage），换设备/清缓存会丢失进度。
- 游戏内自带存档码导出/导入，可跨设备迁移进度。

## 在线游玩

https://yangkwolf.github.io/sanguo-game/

## 本地运行

直接用浏览器打开 `index.html` 即可，或在本目录起任意静态服务器：

```
python -m http.server 8000
```

## 说明

本页面为独立静态站点，不包含任何第三方统计或行为分析脚本。
